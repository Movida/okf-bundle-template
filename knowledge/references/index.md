# Références

Matériel externe recopié dans le bundle : extraits de documentation éditeur,
scripts, exports, captures. Convention OKF § 6.3.

Ces fichiers sont des concepts de première classe : les champs `sources[].resource`
des documents peuvent pointer dessus par un chemin relatif au bundle
(`/references/<fichier>`), ce qui garde la source consultable même si l'URL
d'origine disparaît.

Recopie ici ce qui risque de bouger ou de disparaître à la source. Ne recopie
pas ce qui est stable et bien référencé par URL : la base n'a pas vocation à
dupliquer la documentation éditeur.
